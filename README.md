# CaseDog demo

Static demo of the CaseDog support console (queue matrix, filter side panel, MCP dropdown). No build step, no backend.

Run: `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

Files: `index.html`, `styles.css` (theme via CSS variables), `app.js` (UI behavior and sample data), `mcp.js` (MCP dropdown).
